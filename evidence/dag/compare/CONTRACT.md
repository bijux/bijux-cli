# Comparison Evidence Contract

Comparison evidence must be executable and reproducible.

Requirements:
- Every compare scenario must include a stable scenario id.
- Baselines must reference executable bijux scenarios, not note-only commentary.
- Limitations must be captured in metadata, not external free-form notes.
- Every compare metadata entry must link to an executable bijux evidence asset path.
- Every compare metadata entry must declare explicit non-equivalence limits.
- Comparison evidence cannot be release-blocking unless bijux side is measured and explicitly marked.
- Comparison scenario naming should remain system-neutral and behavior-centric.

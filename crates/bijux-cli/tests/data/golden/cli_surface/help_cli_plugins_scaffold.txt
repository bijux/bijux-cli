Usage: bijux cli plugins scaffold [OPTIONS] <kind> <namespace>

Arguments:
  <kind>
  <namespace>

Options:
  -f, --format <FORMAT>     Output format: text, json, or yaml
      --path <path>
      --force
  -q, --quiet               Suppress command output
      --log-level <LEVEL>   Log verbosity level
      --color <MODE>        ANSI color policy
      --pretty              Pretty-print structured output
      --no-pretty           Emit compact structured output
      --config-path <PATH>  Use explicit config file path
  -h, --help                Print help

Examples:
  bijux cli plugins scaffold python sample-plugin
  bijux cli plugins scaffold python sample-plugin --format json
  bijux help cli plugins scaffold

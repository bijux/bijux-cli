Usage: bijux [OPTIONS] [COMMAND]

Commands:
  cli         
  status      
  audit       
  docs        
  sleep       
  doctor      
  version     
  config      
  plugins     
  repl        
  completion  
  history     
  memory      
  help        Print this message or the help of the given subcommand(s)

Options:
  -f, --format <FORMAT>     
  -q, --quiet               
      --log-level <LEVEL>   
      --color <MODE>        
      --pretty              
      --no-pretty           
      --config-path <PATH>  
  -h, --help                Print help

Command groups:
Runtime:
status      Runtime status summary
audit       Runtime audit report
docs        Documentation audit and links
sleep       Controlled sleep helper for diagnostics
doctor      Runtime health diagnostics
version     Runtime version report

Configuration & Plugins:
config      Configuration management commands
plugins     Plugin lifecycle and diagnostics commands

State & Interaction:
history     History state management
memory      Memory state management
repl        Interactive shell
completion  Shell completion generation
cli         Canonical runtime command namespace

Examples:
  bijux status
  bijux config get foo
  bijux config set foo=bar
  bijux plugins list

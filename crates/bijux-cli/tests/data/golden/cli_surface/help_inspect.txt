Usage: bijux inspect [OPTIONS]

Options:
  -f, --format <FORMAT>     
  -q, --quiet               
      --log-level <LEVEL>   
      --color <MODE>        
      --pretty              
      --no-pretty           
      --config-path <PATH>  
  -h, --help                Print help

Examples:
  bijux inspect
  bijux inspect --format json
  bijux inspect --format yaml

Compatibility note: inspect output includes plugin compatibility warnings when present.

Usage: bijux dev [OPTIONS] [COMMAND]

Commands:
  cli   
  help  Print this message or the help of the given subcommand(s)

Options:
  -f, --format <FORMAT>     
  -q, --quiet               
      --log-level <LEVEL>   
      --color <MODE>        
      --pretty              
      --no-pretty           
      --config-path <PATH>  
  -h, --help                Print help

Subcommand guide:
cli    Maintainer command namespace

Use `bijux dev cli --help` for maintainer command families and examples.

Examples:
  bijux dev cli status
  bijux dev cli routes --text
  bijux dev cli doctor --text

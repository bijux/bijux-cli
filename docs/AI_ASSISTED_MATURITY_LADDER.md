# AI-assisted maturity ladder

## Diagnostics-only

Capabilities:
- structured evidence bundles
- machine-readable failure summaries
- diagnostics answers with citations

## Evidence-guided suggestions

Additional capabilities:
- guardrail-checked action suggestions
- what-changed summaries
- incident similarity hints

## Guarded recommendations

Additional capabilities:
- simulation-validated recommendation quality
- strict operator review workflow
- enforced redaction policy for exported evidence

## Promotion criteria

A level promotion requires:
- quality target achieved in simulation
- no guardrail violations
- operator-facing contract documentation complete

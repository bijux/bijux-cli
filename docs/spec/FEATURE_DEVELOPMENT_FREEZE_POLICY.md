# Feature Development Freeze Policy

Foundation review time is for proving repository shape and truthfulness, not
for widening product scope.

## Freeze rule

During foundation review, prioritize:

- contract alignment
- report completeness
- naming and ownership cleanup
- release-truth documentation

Do not treat foundation review as a lane for opportunistic feature expansion or
surface growth unless required to repair an existing governed contract.

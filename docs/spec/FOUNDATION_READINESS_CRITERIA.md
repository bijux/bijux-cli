# Foundation Readiness Criteria

Foundation review is satisfied only when repository structure, proof surfaces,
and release-facing governance artifacts are all present together.

## Required criteria

- architecture and ownership reports exist under `docs/reports/foundation/`
- core governance contracts exist under `docs/spec/`
- runtime, replay, cache, config, and test-trust surfaces remain backed by
  executable checks
- proof statements and foundation governance posture are present and current

## Reading rule

Use this document to decide whether the repository has the minimum review
surfaces required before deeper release or architecture review proceeds.

# Roadmap ownership

## Capability owners

- Spec and validation contracts: `bijux-dag-core` maintainers
- Runtime determinism and policy execution: `bijux-dag-runtime` maintainers
- CLI contract and output schemas: `bijux-dag-cli` and `bijux-dag-app` maintainers
- Repository governance and release checks: `bijux-dev-dag` maintainers

## Delivery tracking

- Every roadmap item must map to a stable document or executable contract.
- Progress is tracked by merged contract tests, docs updates, and CI gates.
- Ownership handoff requires explicit update of this document and related contract docs.

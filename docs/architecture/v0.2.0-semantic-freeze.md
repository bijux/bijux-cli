# v0.2.0 Semantic Freeze

This document freezes the behavior boundaries for v0.2.0. It is a contract for contributors.

What may decide behavior
- `core/precedence.py` resolves all policy and precedence.
- `core/exit_policy.py` resolves exit behavior from error type + policy.
- `core/runtime.py` executes exits and IO side effects.

What must not decide behavior
- CLI parsing, validation, and formatting layers.
- Infra serializers, emitters, and transport adapters.
- Services and plugins (they consume policies, never infer them).

Why this is frozen
- Predictable CLI behavior for users and automation.
- Clear ownership of policy changes (single resolver, single diff).
- Smaller blast radius when adding flags or outputs.

Non-negotiables
- No policy resolution outside `core/precedence.py`.
- No `sys.exit` outside runtime.
- Output formatting never branches on policy.

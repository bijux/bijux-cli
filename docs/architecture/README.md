# Architecture documentation

Audience: maintainers and architects.  
Owner: architecture group.  
Status: stable.

This directory captures living architecture maps and subsystem boundaries.

## Directory role

- Maintain design maps that explain how modules, runtimes, and boundaries are organized.
- Exclude frozen historical rationale and roadmap discussions.
- Exclude command references and onboarding material.
- Keep one canonical map per architecture surface where possible.

## Link contract

When architecture behavior is normative, reference the canonical contract in `spec/`.

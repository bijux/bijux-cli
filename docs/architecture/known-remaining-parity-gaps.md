# Known Remaining Parity Gaps

Date: 2026-03-09

1. Root help and grouped help formatting are not byte-identical to Python captures.
2. Output payloads for several covered commands remain schema-compatible but not text-identical to Python outputs.
3. Plugin-check stderr diagnostic passthrough differs from Python plugin loader traces.
4. Full command coverage still excludes several Python-only command families outside the current parity set.
5. Python runtime performance baselines for direct command-to-command timing comparisons are not available in the current capture artifact format.

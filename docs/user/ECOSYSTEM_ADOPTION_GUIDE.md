# Ecosystem adoption guide

## Onboarding surfaces

Guides are provided for:
- DAG authors
- tenant admins
- platform admins
- operators

## Capability discovery

Deployments must expose active and preview capabilities for operator inspection.

## Governance and stability

Ecosystem governance defines contribution rules, integration qualification, and official adoption criteria.

A public stability map classifies subsystems as stable, preview, experimental, or research.

## Reference environments

Reference environments are continuously verified against latest releases for local, HA, multi-tenant, and geo-federated modes.

## Adoption scorecard

Platform adoption is tracked across:
- installability
- operability
- integration breadth
- clarity of guarantees

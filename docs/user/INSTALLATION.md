# Installation

Audience: new users and operators.  
Owner: user documentation maintainers.  
Status: stable.

## Supported installation methods
- Build from source:
  - `cargo build -p bijux-dag-cli --release`
- Run from workspace:
  - `cargo run -p bijux-dag-cli -- dag version`

## Shell completions
Shell completion guidance is provided only for stable command trees.
Current recommended approach is direct CLI usage until completion scripts are versioned and tested.

# Known Gaps

Known gaps are tracked as concrete categories, not slogans:
- parity gaps between Rust and Python behavior
- diagnostics and plugin lifecycle maturity gaps
- docs duplication and stale prose risk
- test depth gaps in failure-path and resilience coverage

Authoritative detail comes from generated artifacts:
- `artifacts/parity/rust_python_parity_report.json`
- `artifacts/status/docs_audit.json`
- `artifacts/status/current_rust_state.json`

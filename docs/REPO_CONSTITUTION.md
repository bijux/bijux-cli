# Repository Constitution

## Constitutional boundaries
- kernel semantics are authoritative and backend-agnostic.
- backend adapters map runtime contracts and must not redefine meaning.
- app/CLI surfaces expose contracts and evidence, not aspirational behavior.
- governance tooling enforces drift, compatibility, and release evidence integrity.

## Change discipline
- stable contracts require compatibility fixtures and release notes for breaking changes.
- generated reports must be reproducible from committed scripts and inputs.

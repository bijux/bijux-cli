# Documentation Governance Alignment

Documentation governance exists to keep repository claims, release framing, and
maintainer verification aligned.

## Alignment Rules

- handbook structure should follow package and product ownership
- reports should summarize proof surfaces without inventing new product claims
- capability and maturity language must distinguish implemented, modeled,
  hidden, internal, and future surfaces
- documentation reduction is a quality constraint, not a signal to hide real
  proof or contract ownership

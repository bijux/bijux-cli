# Platform Overview

`bijux-core` combines four documentation surfaces:

- repository-level governance in `bijux-core/`
- CLI program ownership in `bijux-cli/`
- DAG program ownership in `bijux-dag/`
- maintainer workflows in `bijux-dev/`

The root explains shared contracts. Program handbooks explain program behavior.

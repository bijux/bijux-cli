# Fixture Cleanup Automation Report

## Scope

Fixture cleanup is governed as a repeatable maintenance workflow with explicit backlog visibility.

## Automation and diagnostics surfaces

- `docs/reports/foundation/repo_tree_cleanup_candidates_report.md`
- `docs/reports/foundation/unreferenced_fixtures_report.md`
- `docs/reports/foundation/stale_fixture_schema_field_report.md`

## Governance expectation

- unreferenced fixtures are identified and reviewed regularly
- stale schema fields are reported before fixture schema changes ship
- cleanup candidates are tracked as actionable maintenance work

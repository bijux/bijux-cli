# Top 20 Operator Confusion Sources

1. Unsure which command is canonical for quick health.
2. Similar command names with different output depth.
3. Optional JSON flags not consistently documented at command entrypoints.
4. Diagnostics and inspect overlap.
5. Capability and support matrix overlap.
6. Error wording not fully normalized.
7. Output ordering differences between command families.
8. Text output includes details operators do not need by default.
9. Replay and explain terminology differences.
10. Imported-run behavior not surfaced early in help text.
11. Run history and artifact lineage boundaries unclear.
12. Verification suite names not mapped to user-level flows.
13. Evidence outputs too broad for targeted troubleshooting.
14. Missing concise operator examples in selected command docs.
15. Legacy labels still visible in some reports.
16. Dashboard naming overlap.
17. Limited discoverability of command stability guarantees.
18. Default output not always optimized for triage speed.
19. Partial duplication between app and dev-dag diagnostics.
20. Too many similar summary artifacts without audience tags.

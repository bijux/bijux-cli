# Stale Overreach Names in Docs Report

Known stale/overreaching terms still present in documentation and tracked for migration:

- `control-plane`
- `control-plane api`
- `federated scheduler`
- `geo federation`
- `tenant control plane`
- `distributed controller`

These terms are governed through `configs/policy/vocabulary_registry.json` and must not leak into default operator help surfaces.

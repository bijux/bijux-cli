# Dev DAG Command Purpose Map Report

Command purpose classes:

- `release-critical`: gates required for product correctness and release trust
- `maintenance`: upkeep, inventory, and policy consistency checks
- `advisory`: non-blocking diagnostics and optimization guidance
- `legacy`: retained compatibility helpers outside primary surfaces

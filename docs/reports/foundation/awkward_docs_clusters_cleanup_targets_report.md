# Awkward Docs Clusters Cleanup Targets Report

This report identifies documentation clusters likely to drift or confuse operator expectations.

## Cleanup-prone clusters
1. Legacy wording around platform and control-plane semantics.
2. Multiple pages describing similar command behavior with inconsistent examples.
3. Architecture pages missing links to active verification suites.
4. Report indexes where naming is inconsistent with governance taxonomy.

## Direction
- Consolidate duplicated guidance under canonical pages.
- Keep docs vocabulary aligned with supported capabilities.
- Link every stable contract area to direct tests and evidence.

# Awkward Evidence Families Rationalization Report

This report identifies evidence families that still have weak decision value or overlap stronger upstream evidence.

## Rationalization targets
1. Evidence files with redundant topology summaries.
2. Evidence files with no active blocker or release-review consumer.
3. Evidence families that duplicate dashboard-level signals without extra diagnostics value.
4. Low-severity advisory evidence mixed into blocker-oriented directories.

## Rationalization direction
- Every evidence family maps to owner, severity, audience, and decision use.
- Duplicate families are collapsed into a single source of truth.
- Advisory-only artifacts remain isolated from blocker paths.

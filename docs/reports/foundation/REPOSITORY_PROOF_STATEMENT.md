# Repository Proof Statement

## Purpose

This statement explains what “proof” means in this repository.

## Proof Sources

- contract documents under `docs/spec/`
- handbook ownership pages under `docs/bijux-core/`, `docs/bijux-cli/`,
  `docs/bijux-dag/`, and `docs/bijux-dev/`
- executable tests under the owning crates
- generated foundation reports under `docs/reports/foundation/`

## Statement

The repository is considered trustworthy only when human-facing claims can be
traced back to code, contracts, tests, or generated reports that are themselves
derived from those sources.

# Experience surfaces

## DAG author experience

- Build graphs with Rust-native builders and typed DSL helpers.
- Use lint and dry-run preview contracts before execution.
- Use example fixtures as executable references for common patterns.

## DAG operator experience

- Use run artifacts for timeline, metrics, and root-cause reports.
- Use run-control operations for submit/cancel/retry/replay workflows.
- Use backend capability docs to choose correct deployment profile.

## Control-plane experience

- Repository control plane (`bijux-dev-dag`) owns local checks and contract orchestration.
- Runtime control-plane contracts define typed operational requests/responses.
- Future service control plane (`bijux-dag-api`) will provide multi-user orchestration APIs.

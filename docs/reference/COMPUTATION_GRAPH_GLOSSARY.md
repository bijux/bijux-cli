# Computation Graph Glossary

## graph

Canonical DAG definition and identity surface.

## run

Immutable execution record derived from a graph under runtime conditions.

## artifact

Materialized output with content fingerprint and provenance links.

## replay

Re-execution or re-materialization workflow with explicit fidelity checks.

## proof

Evidence-backed claim that a behavior or trust property is verified.

## fidelity

Degree to which replayed behavior is equivalent to source run semantics.

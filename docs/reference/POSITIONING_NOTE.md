# Positioning Note

## Scope

Bijux DAG is positioned as a deterministic computation-graph truth engine.

## Why this is not Airflow, Prefect, or Dagster

- This repository does not claim to be a full workflow platform with hosted control-plane scope.
- This repository prioritizes canonical graph/run/artifact identity and replay/diff proof surfaces.
- Platform breadth claims are constrained by conformance and evidence reports, not by aspirational docs.

## Current focus

- Deterministic local execution semantics.
- Trustworthy run history and artifact lineage.
- Evidence-backed release claims.

## Non-goal

Comparative positioning is not a claim of feature parity with broader orchestration platforms.

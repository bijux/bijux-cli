# AI-assisted guardrails

## Non-negotiable constraints

AI-assisted tooling may:
- summarize evidence
- suggest policy-compliant operator actions

AI-assisted tooling may not:
- bypass policy decisions
- bypass authorization
- execute mutating operations autonomously

## Explainability contract

Each suggestion must cite concrete evidence sources and rationale.

## Review enforcement

No suggestion is final until an authorized operator records an explicit review decision.

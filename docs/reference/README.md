# Reference documentation

Audience: operators and maintainers.  
Owner: documentation maintainers.  
Status: stable.

This section is the canonical command and support reference layer for product operators and platform maintainers.

## Directory role

- Keep command taxonomies, support matrices, schema and evidence indexes, and operational reference tables.
- Exclude tutorials and onboarding content; move that to `user/`.
- Exclude architectural rationale; move that to `architecture/` or `adr/`.
- Keep one source per reference topic to avoid duplicated matrices.

## Source mapping

Reference topics must point to canonical contracts in `spec/` when they describe expected behavior.

## Canonical pages

- `SUPPORT_AND_COMPATIBILITY_MATRICES.md` for all support and compatibility matrix material.
- `GLOSSARY.md` for canonical terminology.
- `COMPARISON_REFERENCE.md` for comparison evidence rules and scenario mappings.

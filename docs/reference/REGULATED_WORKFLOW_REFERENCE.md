# Regulated workflow reference

## Objective

Provide a reference release path for regulated environments where evidence completeness is mandatory before promotion.

## Required controls

- Signed artifact manifests.
- Run-level provenance attestation.
- Environment attestation with explicit trust domain.
- Promotion allowed only for `attested` and `approved` artifact labels.

## Minimum evidence package

- Run attestation payload containing DAG snapshot and plan fingerprint.
- Binary provenance list for scheduler, workers, and CLI.
- Plugin provenance list including trust tier and approval.
- Signed manifest list for all promoted artifacts.
- Verification report generated by `attestation_verify`.

## Verification sequence

1. Build evidence bundle at run completion.
2. Verify completeness with the runtime contract checks.
3. Run CLI attestation verification in CI.
4. Block promotion if verification fails.
5. Store evidence bundle for audit retention.

## Audit expectations

- Every promoted artifact can be traced to an attested run.
- Trust input drift between baseline and replay is documented.
- Policy decisions are reproducible by policy bundle version.

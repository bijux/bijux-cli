# Comparison Evidence Surfaces

## Purpose
Defines the canonical comparison evidence surfaces after root cleanup.

## Canonical roots
- Scenarios: `evidence/compare/scenarios/`
- Baselines: `evidence/compare/baselines/`
- Metadata: `evidence/compare/metadata.json`

## Usage rules
- Public comparison claims must reference committed evidence under `evidence/compare/`.
- External notes may exist in docs, but they are non-authoritative unless linked to executable evidence assets.
- Scenario identity and baseline coverage are validated by repository contracts.

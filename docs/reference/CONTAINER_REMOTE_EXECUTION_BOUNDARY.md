# Container And Remote Execution Boundary

## Current truth

- Local subprocess execution is implemented in runtime execution paths.
- Container execution is contract-simulated and validated through conformance tests.
- Remote execution is contract-simulated and validated through conformance tests.

## Non-claims

- This repository does not claim production-ready remote orchestration.
- This repository does not claim production-ready container fleet control.
- Capability declarations must remain explicit and replay checks must reject unsupported parity assumptions.

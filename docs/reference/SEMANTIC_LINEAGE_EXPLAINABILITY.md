# Semantic lineage explainability

## Explain surfaces

Explain contracts support runs, nodes, datasets, and promoted artifacts.

Each explanation includes concrete semantic relationships and their confidence levels.

## Operator workflows

Recommended operator uses:
- verify why an artifact was approved or promoted
- inspect policy dependency ancestry before release
- identify minimal replay scope after upstream changes

## Conflict triage

When lineage conflicts occur:
1. inspect conflicting edge keys
2. compare declared and inferred claims
3. reconcile imported and local provenance sources
4. re-run verification checks with updated lineage evidence

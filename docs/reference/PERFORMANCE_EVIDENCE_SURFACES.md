# Performance Evidence Surfaces

## Purpose
Defines the canonical performance evidence surfaces after root cleanup.

## Canonical roots
- Scenarios: `evidence/perf/scenarios/`
- Baselines: `evidence/perf/baselines/`
- Runtime benchmark artifacts: `artifacts/benchmarks/`

## Usage rules
- Performance claims must cite scenario-backed evidence from canonical roots.
- Threshold and regression policy are governed from `evidence/perf/baselines/`.
- Measurement format remains governed by `configs/schema/benchmarks/benchmark_report.schema.json`.

# Elite MVP scorecard

## Artifact-first

- [x] Artifact contracts are typed and versioned.
- [x] Lineage and visualization exports are generated.
- [x] Artifact verification and reproducibility checks exist.

## Deterministic snapshots

- [x] Graph canonicalization contract is explicit.
- [x] Run snapshot and manifest contracts are versioned.
- [x] Scheduler deterministic ordering rules are documented and tested.

## Typed contracts

- [x] Task, run, scheduler, control-plane, and infrastructure contracts are typed.
- [x] Backend capability negotiation is typed and validated.
- [x] Plugin and DSL extension contracts are explicit.

## Replayable runs

- [x] Replay provenance is captured in traces/manifests.
- [x] Run comparison and failure propagation records are persisted.
- [x] Example fixtures include replay-heavy patterns.

## Observability

- [x] Structured events, metrics, timelines, and root-cause artifacts are emitted.
- [x] Control-plane audit stream is persisted.
- [x] Observability docs and fixtures are included.

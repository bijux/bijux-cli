# Rust Config Parity

Config parity truth is generated, not maintained as hand-written narrative.

Use these evidence sources:
- `artifacts/parity/config_parity_report.json`
- `artifacts/parity/command_parity_matrix.json`
- `artifacts/status/status_state_behavior_coverage.json`

Use this diagnostics command:
- `bijux dev cli status --format json`

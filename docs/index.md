# Bijux CLI

Bijux CLI is a lean, plugin-driven command-line interface with a strict
execution model, predictable exits, and explicit configuration precedence.

Start here:

- Get started: get_started.md
- Concepts: concepts/architecture.md
- Guides: guides/cli_usage.md
- Reference: reference/commands.md
- Examples: examples/basic_example.md
- FAQ: faq.md
- Glossary: glossary.md

Philosophy (short): make behavior explicit, avoid hidden defaults, and keep the
CLI contract stable even as plugins and features evolve.

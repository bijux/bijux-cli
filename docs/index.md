# Bijux CLI

## Purpose
This page guarantees how to navigate the documentation set.

## Scope
It does not document CLI behavior or APIs.

## Core Concepts
- Documentation is organized by purpose.
- Each section has an index page.

## Invariants
- Index pages are the entry point for each section.

## Execution
Use the links below to reach the correct layer.

- Getting Started: getting-started/index.md
- Concepts: concepts/index.md
- Guides: guides/index.md
- Reference: reference/index.md
- Examples: examples/index.md

## Failure Modes
- Broken links are treated as build failures.

## Design Rationale
- Alternatives: a single monolithic README.
- Rejected because it hides scope and encourages duplication.
- Chosen: structured sections with clear intent.

## Non-Goals
- Detailed CLI documentation.

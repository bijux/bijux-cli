# Guides

## Purpose
Guides provide specialist instructions that sit beyond the main user journey.
They exist for installation detail, API embedding, contributor work, and other
focused workflows that do not belong in the core user guide.

## Scope
This section focuses on focused workflows outside the main user path. It does
not duplicate the introduction, getting-started, or user-guide sections.

## Audience
Engineers with a specific non-default workflow should start here. Each guide is
written as a focused path from goal to result.

If you are still setting up the runtime, start with
[Getting started](../02-getting-started/index.md).

If you want normal day-to-day usage guidance, start with
[User guide](../03-user-guide/index.md).

## What You Will Find
Each guide explains a single workflow, its prerequisites, the exact commands to run, and the expected outcomes. The goal is to keep each guide short, precise, and actionable.

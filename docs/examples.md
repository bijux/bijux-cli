# Examples {#top}

Practical, copy-pasteable examples for common Bijux CLI workflows.

## Plugin Scaffold (Local Template)

```bash
bijux plugins scaffold my_plugin --template ./plugin_template --output-dir ./plugins
```

## Basic CLI Usage

```bash
bijux status --format json
bijux help
```

## REPL Session

```bash
bijux repl
```

## Configuration Quickstart

```bash
bijux config set foo.bar baz
bijux config get foo.bar
```

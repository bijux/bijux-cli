# Testing documentation

Audience: maintainers and contributors.  
Owner: quality maintainers.  
Status: stable.

This folder hosts testing process guidance for maintainers.

## Directory role

- Keep contributor and maintainer test workflows here only.
- If tests are user-facing instructions, move content to `user/`.
- If test behavior is part of normative guarantees, move the contract text to `spec/`.
- Keep the number of files low and avoid duplicate test taxonomies.

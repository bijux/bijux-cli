# Repository Root Pillars

This repository is intentionally centered on five durable top-level pillars:

- `crates/`: executable product and developer control-plane code.
- `docs/`: contractual and operational documentation.
- `evidence/`: governed proof assets, metadata, registries, and reports.
- `configs/dag/`: schemas, policy definitions, and contract-checked configuration.
- `make/`: repeatable automation entrypoints for local and CI usage.

All new root-level additions must be justified against these pillars and approved by repository governance rules.
